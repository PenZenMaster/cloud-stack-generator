# External Code Directory

This directory contains external code references and imports.

## Contents

### product-import-with-schema/
Schema-based product import utilities:
- import_salvo_schema.py - Schema import script
- product-catagory-with-schema.csv - Sample data with schema
- schema_out/ - Generated schema output files
- Sample run logs and documentation

## Purpose

External code is kept separate from core application code to:
- Maintain clear boundaries between internal and external dependencies
- Provide reference implementations
- Enable easy comparison with external approaches

## Usage

These files are reference materials and should not be directly integrated into the core application without proper review and adaptation.
