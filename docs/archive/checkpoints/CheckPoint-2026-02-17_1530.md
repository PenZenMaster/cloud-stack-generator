### Code Patterns Introduced

**Robust JSON Extraction Pattern:**
```python
def _extract_json(self, content: str) -> Dict[str, Any]:
    # Strategy 1: Direct parse
    try:
        return json.loads(content)
    except json.JSONDecodeError:
        pass

    # Strategy 2: Extract from code fences
    if "```json" in content:
        start = content.find("```json") + 7
        end = content.find("```", start)
        if end > start:
            try:
                return json.loads(content[start:end].strip())
            except json.JSONDecodeError:
                pass

    # Strategy 3: Find first { to last }
    first_brace = content.find("{")
    last_brace = content.rfind("}")
    if first_brace != -1 and last_brace != -1:
        try:
            return json.loads(content[first_brace:last_brace + 1])
        except json.JSONDecodeError:
            pass

    raise ValueError("Could not extract valid JSON")
```

This pattern handles:
- Pure JSON responses
- JSON wrapped in markdown code fences
- JSON embedded in explanatory text
- Graceful error handling with fallback

## Design Variations & Rationale

### JSON Extraction Strategy

**Problem:** Claude 4.5/4.6 models sometimes return JSON wrapped in markdown code fences or explanatory text, causing `json.loads()` to fail.

**Solution Options Considered:**
1. Use structured output API (requires different API endpoint)
2. Regex to extract JSON
3. Multi-strategy extraction with fallbacks

**Decision:** Multi-strategy extraction (Option 3)

**Rationale:**
- Most flexible - handles all response formats
- No API changes required
- Easy to understand and maintain
- Graceful degradation (tries 3 strategies before failing)
- Works with current Claude API

**Implementation:**
```python
def _extract_json(self, content: str) -> Dict[str, Any]:
    # 1. Try direct parse (pure JSON)
    # 2. Extract from ```json code fences
    # 3. Extract from ``` generic code fences
    # 4. Find first { to last } and parse
    # 5. Raise ValueError if all fail
```

This pattern is reusable across all LLM providers (OpenAI will need it too).
