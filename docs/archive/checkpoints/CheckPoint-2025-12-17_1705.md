# AWG Checkpoint - 2025-12-17 17:05

## Context Summary

Session focused on critical bug fix for backlink site architecture. User reported that backlink sites (d2kqaxeqy8leud.cloudfront.net and dfoay4cvr1g82.cloudfront.net) were configured as mirror/duplicate sites instead of independent sites providing backlink value to main site.

Root cause: v3.6.0 introduced incorrect canonical URL logic that pointed backlink sites to main_site_url, causing Google to treat them as duplicates instead of independent sites.

## Accomplishments

### 1. Identified and Fixed Critical Backlink Site Bug

**Bug**: Backlink sites had canonicals pointing to main site instead of CloudFront URL
- This caused Google to treat them as duplicates (zero backlink value)
- Sites appeared as mirrors instead of independent backlink sites

**Root Cause**: Three generators had inconsistent/incorrect `_get_canonical_base_url()` logic
- `html_generator.py` - Used main_site_url for backlink sites (WRONG)
- `page_generator.py` - Old v3.5.0 logic checking deployment_url
- `city_page_generator.py` - Hardcoded relative URLs for page_url

### 2. Fixed Three Generator Files

**Unified canonical logic across all generators**:
```python
def _get_canonical_base_url(self):
    # Use deployment_url for both main and backlink sites
    if config.cloud.deployment_url:
        return config.cloud.deployment_url.rstrip("/")
    return config.business.domain.rstrip("/")
```
