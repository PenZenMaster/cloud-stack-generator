## Accomplishments

- **#33 CLOSED (f6df206)** - Removed hardcoded fabricated `aggregateRating` (4.5/10 reviews) from
  every Product schema. Now gated behind real `ProductConfig.rating`/`review_count` data.
- **#34 CLOSED (6883d9e)** - `BACKLINK_SITE_IMPLEMENTATION.md` had a self-contradictory section
  describing the v3.6.0 canonical regression (canonical -> `main_site_url`) as current/recommended
  behavior. Corrected to match the shipped v3.7.1 fix (canonical always self-references
  `deployment_url`). Added a regression test and a single-source-of-truth note in
  `SEO_AND_INDEXING.md`.
- **#35 CLOSED (5b5ecdc)** - Issue named `CityContentGenerator._generate_template_city()` as the
  source of scaled near-duplicate city content, but that code turned out to be dead in production
  (writes to an `ai_generated_content` context key no template reads). Redirected the fix to the
  real mechanism: `seo_authority_city_page.html`'s `{% else %}` boilerplate blocks, which fire
  unconditionally whenever `about_city`/`seo_content_body` are empty. Added `ContentQualityGate`
  that aborts a batch generation when more than `template_fallback_page_limit` (default 10) pages
  would render boilerplate, unless `allow_template_fallback` is set. New `--allow-template-fallback`
  CLI flag; warning surfaced in the generation-complete dialog.
- **#36 CLOSED (6355daf)** - City page templates hardcoded `["WebPage", "LocalBusiness"]` plus the
  client's real NAP data unconditionally, even on buffer/resource properties, fragmenting local-pack
  NAP signals across the network. Added `resolve_entity_schema()`: LocalBusiness+NAP only for
  `main_site` with a publicly exposed address; `Organization` for backlink_site; `WebPage` alone for
  resource sites. Reviewed provider templates per the issue's own question - confirmed their
  LocalBusiness markup describes third-party providers, not the resource site's own identity, so no
  change needed there.
- **#37 CORE ENGINE COMMITTED, issue left OPEN (4c8a98e)** - Anchor-text rotation engine. User
  explicitly scoped this to "core engine only" (config + selector + template wiring + tests), with
  the UI pool/distribution editor and `anchor_report.json` artifact deferred as follow-up work.
  Added `AnchorProfileConfig` (YAML round-trip), `AnchorSelector` (seeded, drift-correcting toward
  target distribution, no intra-page repeats, safety ceiling on exact-match share, auto-generated
  default pools), wired as a Jinja global into both `HTMLGenerator` and `CityPageGenerator`. All 6
  hardcoded anchors replaced. Found and fixed a blocking pre-existing gap along the way:
  `city_page_generator.py` never set `is_backlink_site`/`main_site_url`, so the entire backlink CTA
  section in the live city template never rendered for any city page - the anchor fix would have
  been inert without it.
- **926 -> 979 tests passing** across the session (53 new tests added), **0 regressions** - the
  same 83 pre-existing failures (test_backup_manager, test_template_preview, test_template_validator,
  etc.) persisted unchanged throughout.
